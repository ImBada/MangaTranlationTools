# Rust(egui) 이전 TODO

기존 TS/Electron 앱(`src/`)을 Rust 네이티브 앱(`native/`)으로 옮기는 작업 목록입니다.
보관함 데이터 형식(`~/Documents/MangaTranslationTools/library`)은 그대로 유지해서 두 앱이 같은 데이터를 읽고 쓸 수 있게 합니다.

상태: `[ ]` 미착수 · `[~]` 진행 중 · `[x]` 완료(테스트/셀프 리뷰 통과)

## 원칙

- 디스크 형식 호환: 모르는 JSON 필드는 `extra`로 보존해서 TS 앱과 왕복해도 데이터가 사라지지 않게 한다.
- 저장은 임시 파일 + rename 원자적 쓰기. 네이티브 앱이 처음 쓰는 chapter.json은 1회 백업(`chapter.json.native-backup`).
- 편집 화면과 PNG 출력은 같은 렌더러(`mtt-render`)를 쓴다. (기존 앱의 DOM/캔버스 이중 렌더 경로 제거)
- 레이어 픽셀은 프로세스 메모리에 두고 PNG로 직접 저장한다. (dataURL 왕복·저장 큐 제거)
- 각 단계 끝에 `cargo fmt`, `cargo clippy -D warnings`, `cargo test` 통과 + 셀프 리뷰.

## 크레이트 구조

| 크레이트 | 역할 | 대응하는 기존 코드 |
|---|---|---|
| `mtt-core` | 데이터 모델, 경로, 설정, 보관함 저장소, 가져오기 | `src/shared`, `src/server/library*`, `appSettings`, `settingsStore` |
| `mtt-render` | 텍스트 레이아웃, 블록/페이지 렌더링 | `overlayLayout.ts`, `pageRender.ts`, `hardTextRendering.ts`, `fontFilterEffects.ts` |
| `mtt-inpaint` | 마스크 처리, 로컬 채우기 인페인트, LaMa(파이썬 사이드카), 블록 글자 마스크 | `inpaintEngine.ts`, `libraryImageData.ts`, `inpaintMaskImages.ts` |
| `mtt-translate` | LLM 번역 파이프라인 | `wholePagePipeline.ts`, `runtime/*.cjs` |
| `mtt-app` | egui 앱 | `src/client` 전체 |

## 9단계: UI 개편 (이식 완료 후)

TS 화면 구성을 그대로 따르던 UI를 작업 흐름 중심으로 다시 짠다. 기능은 그대로 두고 배치만 바꾼다.

작업 흐름: 화 열기 → AI 번역 → 페이지별 문장 확인·수정 → 인페인트(원문 지우기) → 보정 → 검수·출력.

- [x] 테마 (간격, 모서리, 색, 글자 크기 통일)
- [x] 상단 바: 보관함으로, 작품 › 화 전환 목록, 모드 탭(번역 · 인페인트 · 검수/출력), AI 번역 메뉴/진행, 설정
- [x] 레이어 번호 대신 모드. 1~5 단축키는 유지(5 = 원본 보기 토글), 표시/투명도는 캔버스 툴바의 "보기" 팝오버로
- [x] 페이지 스트립: 썸네일(필요할 때 배경에서 생성), 번호·이름, 번역/인페인트/완료 표시, 우클릭 메뉴, 드래그 순서 변경
- [x] 캔버스 툴바: 모드별 도구(좁으면 두 줄), 오른쪽에 원본/보기/배율. 브러시 크기는 인스펙터와 `[ ]`. 캔버스 위 떠 있는 패널 제거(선택 블록 옆 빠른 조작만 유지)
- [x] 인스펙터(오른쪽 패널 하나): 번역 = 블록 목록 ↔ 블록 편집(문장 먼저, 스타일은 접는 섹션), 프리셋 탭 / 인페인트 = 실행·도구 옵션·PSD / 검수 = 완료 표시·출력·보고서
- [x] 블록 사이 이동 (Tab / Shift+Tab, 인스펙터의 ‹ ›)
- [x] 하단 상태 바: 저장 상태, 페이지 정보, 최근 메시지(누르면 기록), 작업 진행
- [x] 보관함 화면: 작품 목록 | 화 목록(진행률), 가져오기 메뉴, 파일/폴더 끌어다 놓기로 가져오기, LaMa 준비 안내 배너
- [x] 설정: 탭(번역 · 인페인트 · 편집 · 정보)
- [x] 프리셋 칩 + "새 프리셋으로 저장" (선택 블록 또는 편집 중인 프리셋에서)
- [x] 인스펙터 폭 고정: 내용이 패널을 넓히지 않게 글꼴 선택·굵기·렌더링 콤보 폭 제한 (스타일 섹션을 모두 펼쳐도 297px 안)

- [x] 툴바·상단 바 아이콘 (Phosphor 아이콘 글꼴, `assets/fonts`), 좁은 캔버스에서는 원본/보기를 아이콘만
- [x] 단축키 표시: 도구·모드 탭·페이지/블록 이동·주요 버튼 옆에 작은 키 글자, 전체 단축키 표(`?`, 상태 바 `단축키`, 설정 › 편집), 키 이름은 OS에 맞게(⌘ → Ctrl+ 등, `src/shortcuts.rs`)
- [x] 마우스를 올리면 버튼이 1px 커져 옆이 흔들리던 문제: 활성 테두리를 버튼 stroke 대신 위에 그리고, 올렸을 때 글자색 유지 (회귀 테스트 `hovering_buttons_does_not_move_anything`)

- [x] 화면 검토(서브 에이전트 스크린샷 리뷰) 반영: 모드별 레이어 표시 정리(번역 = 최종 모습, 인페인트 = 글자 없이), 아직 인페인트 안 한 페이지·원본 보기·미리보기 안내, 전체 다시 번역·설정 기본값 복원 확인 창, LaMa 안내를 한 줄 배너로, 빈 보관함 첫 화면, 용어 통일(인페인트 / 검수 완료), 블록 동작을 문장 바로 아래로, 캔버스 빠른 조작 한 줄(정렬 아이콘·자동 크기·스타일 복사), 프리셋 칩 높이 통일·한글 표시 이름·삭제는 프리셋 탭에서만, 그룹 그림자 단위·꺼지면 비활성, 대화상자 뒤 어둡게, 1100 폭 보관함 잘림
- 번역 모드 Space 미리보기가 평소 화면과 거의 같음(블록 배경·테두리·핸들·빠른 조절 줄이 그대로) → 원래 앱처럼 모두 숨김, Space+클릭은 선택하지 않고 손 커서, 그리기 전에 Space 상태 판단
- 인페인트 결과(3)·마스크(4)에서 원본 이미지를 50% 투명도로 (기존 앱과 같은 값, 번역 오버레이는 계속 숨김)
- 원본 투명도를 낮추면 페이지 뒤 배경을 흰색 대신 검정으로 → 마스크와 지운 자리가 잘 보임
- 남긴 것: 모드 단축키 순서(2 / 3·4 / 1)는 기존 앱 습관 때문에 그대로 둠

검증: 1440×960 / 1100×720에서 각 모드 스크린샷, 목 서버로 가져오기 → AI 번역 → 수정 → 전체 인페인트 → 보고서 → 출력 자동화 통과, clippy -D warnings, 테스트 전부 통과.

### 9단계 (UI 개편)

- 블록을 고르면 인스펙터가 44px 넓어져 캔버스가 다시 맞춰짐 → 글꼴 콤보가 글꼴 이름만큼 커지던 것. 콤보 폭 고정 + 말줄임, 굵기를 별도 줄로.
- 좁은 창(1100)에서 캔버스 툴바가 캔버스 전체를 차지 → 구분선이 패널의 남은 높이 전체로 늘어남. 툴바 계산 높이를 한 줄로 제한.
- 툴바가 두 줄로 넘칠 때 들여쓰기가 어긋남 → 비활성 묶음(`add_enabled_ui`)이 자기 안에서 줄바꿈. 버튼마다 활성 여부를 넘기도록 변경.
- Tab을 egui에 그대로 두면 첫 버튼(← 보관함)에 포커스가 가고, 화면 이동용 Space가 그 버튼을 누름 → 텍스트 입력 중이 아닐 때는 `raw_input_hook`에서 Tab을 가로채 블록 이동으로 사용.
- 상태 바 최근 메시지가 안 보임 → 오른쪽 묶음을 그린 뒤 커서 위치로 영역을 계산해 폭이 음수. 그리기 전 위치로 계산.
- 선택 블록의 빠른 조작이 블록이 화면 밖일 때 툴바·상태 바 위에 떠 있음 → 캔버스와 겹치지 않으면 숨김.
- 독립 리뷰(서브 에이전트) 지적 반영:
  - FOCUS MODE를 끄면 `원본`(5)이 다른 레이어를 그대로 그림 → 원본 보기에서는 원본 이미지만 그리도록.
  - 인페인트 그룹 투명도 조절이 사라져 결과 슬라이더가 20%에 묶임 → `보기`에 "인페인트 (결과+마스크)" 줄 복원.
  - 원본 보기 중 인페인트 패널이 결과 레이어로 동작 → 기억해 둔 인페인트 레이어 기준, 원본 보기 중에는 칠하기 도구 비활성.
  - 인페인트·번역 실패도 상태 바에 "저장 실패"로 표시 → 저장 실패만.
  - Tab 블록 이동이 한 프레임 늦게 보임 → 그리기 전에 적용 + 다시 그리기 요청.
  - 원본 보기 중 고른 블록이 돌아올 때 이전 선택으로 덮임 → 고른 블록 유지.
  - 인페인트 중 블록 문장·배치·복제·삭제 잠금(TS 블록 패널과 같게).
  - 끌어다 놓기: 지원하지 않는 파일만 놓았을 때 안내 문구, 편집 화면에서는 상태 바로 오류 표시, 막힌 이유별 안내.
  - 페이지 목록이 매 프레임 페이지·화 전체를 복제 → 복제 없이 참조.
  - 긴 화 제목·페이지 이름·프리셋 이름이 상단 바·인스펙터를 밀어냄 → 말줄임(카드 제목 회귀 테스트 추가), 프리셋 이름 칸·진행 막대 폭을 남은 폭 기준으로.

### 8단계 독립 리뷰 (2026-10-27)

별도 리뷰에서 나온 결함과 수정:

- 마지막 페이지 삭제 시 패닉 → 페이지 0개를 처리 (회귀 테스트)
- 프리셋/찾아바꾸기 undo 단계의 페이지를 지우면 undo가 막힘 → 화 단위 단계는 페이지 없이도 적용 (회귀 테스트)
- 전체 인페인트 중 대기 페이지를 지우면 큐가 멈춤 → 큐에서 빼고 진행 (회귀 테스트)
- 인페인트 중 칠한 마스크/결과가 결과 도착 시 사라짐 → 인페인트·번역 대기 중에는 레이어 칠하기 차단 (TS `inpaintDisabled`)
- `work.json`에 id가 없거나 복사된 폴더면 다른 작품/보관함 전체를 지울 수 있음 → 폴더 이름을 id로 사용, 삭제는 `work.json`이 있어야 함 (TS `deleteWork`), 경로 문자 거부 (테스트)
- 동기 `flush` 뒤에 대기 중이던 예전 저장이 덮어쓸 수 있음 → 쓰기 세대 잠금: flush 후 대기 저장은 건너뛰고 flush가 그 내용까지 기록
- 페이지 이동 시 인라인 편집 내용 유실 → 이동 전에 확정
- 배경 투명도 편집 중 표시 체크만 바꿔도 모든 블록 투명도 덮어씀 → 슬라이더 변경일 때만, 잠금 확인
- "인페인트 중" 상태가 보고 있던 페이지에 붙음 → 실행 페이지에 기록, 인페인트 중 나가기/일괄 번역 진행 차단
- 번역 대기 페이지 잠금 우회(Alt+드래그, ⌘클릭 복제, 더블클릭/E) → 막음
- ₩ 한 번에 완료 토글 두 번 → 한 번만
- "만들기"가 다른 블록의 스타일을 복사 → 기본 선택 블록 기준
- 다른 페이지 번역 결과가 열린 프리셋 undo 단계에 섞임 → 결과 적용 전에 단계 닫기
- 스포이드 결과가 나중에 다른 필드에 들어감 → 2프레임 안에 안 쓰이면 버림
- 드래그 시작 위치가 egui 임계값 이후 위치 → 누른 위치 기준 (핸들 놓침 해결)
- undo 후 선택 기록이 어긋남, 삭제 undo 시 선택 복원 안 됨 → 수정
- 결과 색상 추출이 마스크로 가려진 원본 결과를 샘플 → 최종 출력 합성으로 샘플
- 이름 변경/화 순서 오류 메시지가 바로 지워짐 → 새로고침 뒤에 표시
- 페이지/화 드래그 위치를 TS(`before`)와 맞춤, 완료 체크박스가 페이지를 옮기지 않게, 글꼴 검색칸 클릭 시 목록 유지, 즐겨찾기 토글은 undo 단계 아님, 목록 Shift 범위 기준점이 캔버스 선택을 따름

알려진 작은 차이: 같은 상태 문구가 연속으로 나오면 토스트를 다시 띄우지 않음.

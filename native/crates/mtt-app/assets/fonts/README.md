# 아이콘 글꼴

`Phosphor.ttf`: [Phosphor Icons](https://phosphoricons.com) 2.1 regular 굵기.
글꼴 이름 테이블에 적힌 라이선스는 MIT입니다(<https://raw.githubusercontent.com/phosphor-icons/homepage/master/LICENSE>).

[egui-phosphor](https://github.com/amPerl/egui-phosphor) 0.14.0 크레이트(MIT OR Apache-2.0)에 들어 있는 파일을 그대로 가져왔습니다.
그 크레이트는 egui 0.36용이라 의존성으로 쓰지 않고 글꼴만 넣었습니다(`Phosphor-LICENSE-MIT.txt`는 그 크레이트의 라이선스 파일).
아이콘 코드포인트는 `src/theme.rs`의 `icon` 모듈에 있습니다.
